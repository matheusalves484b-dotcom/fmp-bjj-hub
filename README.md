# FMP BJJ Hub

Quero construir um sistema SaaS de gestão para academias de artes 

marciais (Jiu-Jitsu, Muay Thai, Judô etc), chamado "Gestão FMP BJJ". 

Painel administrativo moderno e limpo, com tema em tons escuros e um 

detalhe de cor (ex: vermelho ou azul), pensado pra ser usado por donos 

de academia, professores e alunos.
